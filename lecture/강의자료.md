# Week 1. IaC 개념 & Terraform 기초

### [개념] 오늘의 목표
설치·자격증명을 확인하고 **첫 리소스(S3 버킷)**를 `apply` → `state list` → `destroy`까지 한 사이클 돈다. Terraform의 3대 명령 `init / plan / apply`(+ `destroy`)를 몸에 익히는 게 전부다.

### [실습] 1. 도구 버전 확인
```bash
terraform version      # >= 1.9 확인
aws --version          # aws-cli 설치 확인
aws sts get-caller-identity   # 내 자격증명이 먹히는지 확인
```

### [확인] 자격증명 OK
`get-caller-identity`가 `Account`, `Arn`(내 IAM 사용자)를 JSON으로 출력하면 성공.

### [함정] 자격증명이 안 잡힐 때
`Unable to locate credentials` → `aws configure`로 AccessKey/Secret/`ap-northeast-2` 등록.
`ExpiredToken` / `AccessDenied` → 키가 만료·비활성. IAM에서 재발급. **루트 계정 키는 쓰지 말 것.**

### [실습] 2. 작업 폴더 & provider 설정
```bash
mkdir week1 && cd week1
```
`main.tf` 작성:
```hcl
terraform {
  required_version = ">= 1.9"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}

provider "aws" {
  region = "ap-northeast-2"
}
```

### [실습] 3. 첫 리소스 — S3 버킷
같은 폴더 `main.tf` 아래에 추가 (버킷명은 **전 세계 유일**해야 함 → 본인 영문이름/숫자 붙이기):
```hcl
resource "aws_s3_bucket" "first" {
  bucket = "boaz26-tf-week1-kdh1834"   # ← 본인만의 유일한 이름으로 변경

  tags = {
    Project = "boaz26-terraform"
    Week    = "1"
  }
}
```

### [실습] 4. init → plan → apply
```bash
terraform init      # provider 다운로드, .terraform/ 생성
terraform plan      # 무엇이 만들어질지 미리보기
terraform apply     # yes 입력
```

### [확인] apply 성공 신호
- `Plan: 1 to add, 0 to change, 0 to destroy.`
- 마지막에 `Apply complete! Resources: 1 added.`

### [함정] `BucketAlreadyExists` / `BucketAlreadyOwnedByYou`
버킷 이름이 겹친 것. `bucket` 값을 더 유니크하게(이름+날짜+랜덤숫자) 바꾸고 다시 `apply`.

### [실습] 5. state 들여다보기
```bash
terraform state list          # Terraform이 관리 중인 리소스 목록
terraform state show aws_s3_bucket.first   # 상세 속성
ls -a                          # terraform.tfstate 파일 확인
```

### [개념] 방금 무슨 일이 일어났나
`apply` = (1) 코드대로 AWS에 리소스 생성 → (2) 그 결과를 **`terraform.tfstate`**(로컬 파일)에 기록. state는 "코드 ↔ 실제 클라우드"를 잇는 **장부**다. 다음 `plan`은 이 장부와 실제를 비교해 차이만 계산한다.

### [정리] destroy 체크리스트
```bash
terraform destroy    # yes
terraform state list # (아무것도 안 나와야 정상)
```
